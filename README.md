# CodexDog 🐶

**给 Codex 省流量的桌宠。** 点一下桌面上的小黑，它会把 [Codex](https://openai.com/codex/) 会话里攒下的历史图片清掉，让 Codex 不再每轮对话都把旧截图重新上传一遍，省下流量和 VPN / 代理额度。

> 非 OpenAI 官方项目。

## 它解决什么问题

在 Codex 里贴过截图、或者让它截过屏（computer use、浏览器操作、看设计稿……）之后，这些图片会以 base64 的形式**原样存进会话文件**（`~/.codex/sessions/*.jsonl`）。

问题在于：**之后在这个对话里的每一轮，Codex 都会把整段上下文、连同这些旧图片一起重新发给服务器。**

- 一张截图几百 KB 到几 MB，对话里攒了几十张，每发一句话就要上传几十 MB；
- 长对话用一下午，几个 GB 的上行流量就没了；
- 走 VPN / 机场 / 代理的话，**额度就这样被悄悄烧光**，回复也越来越慢；
- 那些图片早就看过了，模型其实不需要每次都再看一遍。

CodexDog 把会话文件里的这些内嵌图片替换成 1×1 的透明占位图。对话结构不变，可以照常继续聊，只是旧图片不再随每轮请求上传。实测一个 333 MB 的会话文件里，绝大部分体积都是这类重复携带的图片。

## ✅ 本版本已修复：清理后聊天记录打不开 / 错乱

新版 Codex 除了会话文件，还在 `~/.codex/thread_history_1.sqlite` 里**按字节位置**索引每一轮对话。早期的清理方式直接把图片删短，文件长度一变，索引全部错位，重新打开 Codex 后**聊天记录显示为空或错乱**。

这个版本做了两件事：

1. **清理不再改变文件长度**：被替换掉的图片位置用空格补齐（JSON 允许尾随空白），每一行的字节数和原来完全一样，Codex 的索引始终对得上。
2. **附带修复工具 `repair_history.py`**：如果你之前用旧方法清理过、记录已经打不开，运行它就能找回。它对照数据库里记录的位置，把被缩短的行补回原长度，**不删除、不修改数据库**，会话内容本来就都还在。

```bash
python3 repair_history.py --dry   # 先检查，不做修改
python3 repair_history.py         # 修复（会先退出 Codex）
```

实际使用中，它把 44 个被旧版清理弄乱的对话全部恢复，修复后逐个核对索引位置全部吻合。

## 小黑

除了干活，小黑也是只正经的桌宠：

- **平时躲着**，不占桌面。在屏幕右下角 1.2 秒内左右来回晃 4 次鼠标，光标变成一根淀粉肠，小黑从屏幕底边钻出来，先正面站起来冲你讨吃。
- **追淀粉肠**：小黑侧身作揖，一蹦一蹦地追着光标跑，追上就吃掉；15 秒没追上会扑上来抢。
- **闲着**：时不时蹲下来左右张望；鼠标停在它身上会眯眼享受，停久一点就翻肚皮让你摸。
- **没人理**：15 秒后趴下睡觉（Zzz…），鼠标放上去会醒；45 秒后跑回角落躲起来。
- **单击**：清理图片（先退出 Codex / ChatGPT，清完重新打开）。
- **右键**：立即清理、躲起来、开机自动启动、重新抠图、退出。

小黑的形象和动作都来自真狗的照片和视频（作揖、张望、睡觉、翻肚皮……），用 macOS 自带的 Vision 抠图，第一次启动时生成并缓存到 `~/Library/Application Support/CodexDog/`。

## 安装

需要 macOS 14+ 和 Xcode 命令行工具（`xcode-select --install`）。

```bash
git clone https://github.com/zio005792-blip/CodexDog.git
cd CodexDog
bash install.sh
```

装到 `~/Applications/CodexDog.app` 并自动打开。不想要桌宠，也可以只用脚本：`python3 clean_images.py`。

卸载：右键 → 退出，然后删掉 `~/Applications/CodexDog.app`。

## ⚠️ 清理前请知道

- 清理会**直接改写** `~/.codex` 下的会话文件，**不做备份**；清掉的图片无法恢复，模型之后也看不到这些旧图片。
- 清理前会退出 Codex / ChatGPT，**正在跑的任务会被打断**，请在空闲时清理。
- 因为要保持字节数不变，**文件在磁盘上不会变小**——省的是每轮对话的上传流量，不是硬盘空间。

## 文件

| 文件 | 作用 |
| --- | --- |
| `clean_images.py` | 清理 Codex 会话里的内嵌图片（保持字节数不变） |
| `repair_history.py` | 修复旧版清理造成的聊天记录错乱 |
| `main.swift` | 桌宠本体（AppKit + Core Animation） |
| `install.sh` | 编译并安装 |
| `photos/` | 小黑的照片、作揖动作帧和淀粉肠 |

## 小提示

- 为了在后台把系统箭头换成淀粉肠，用了一个私有的 CoreGraphics 开关（`SetsCursorInBackground`）。系统不支持时，箭头会和淀粉肠同时显示，其他功能不受影响。
- 想换成自己家的狗：替换 `photos/` 里的图片，调整 `main.swift` 里 `POSES` 的 `crop` / `erase`，然后右键 → 重新抠图。
